# Skills

Each folder here is one agent skill: a `SKILL.md` file with a small header
(`name` and `description`) followed by plain-Markdown instructions.

To add a skill, create `skills/<your-skill-name>/SKILL.md` and restart the server.
The folder name must match `name`, using lowercase letters, numbers and hyphens.
The chat UI picks it up automatically.

The format follows the open Agent Skills standard: https://agentskills.io/specification
